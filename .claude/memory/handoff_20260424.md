2026-04-22 말 ~ 24 세션. 힐러가 전투 내내 참고할 수 있는 상시 메모 프레임을 맥앱 + 애드온 양쪽에서 편집 가능하도록 신설. 여러 라운드 리뷰(BLOCKER 2 + SUG 4 + NIT 2) 반영 + 인게임 동작 버그 픽스까지 완료.

**Why:** 스크린샷 기반 힐러 치트시트 (힐사이클/쿨기 우선순위/기믹 메모) 를 전투 내내 화면에 고정 표시할 수단이 없었음. 전술 패널은 보스 시전 중에만 떴다 사라지므로 상시 참고용으로 부적합. 맥앱에서 편집한 내용이 인게임에 즉시 반영되고 캐릭터별 조정도 가능한 구조가 필요했음.

**커밋 예정 (이 세션에서 푸시 대상):**
- 애드온 신규: `Data/HGPT_Memo.lua`, `UI/MemoFrame.lua`
- 애드온 수정: `Core/EncounterEngine.lua` (priority=note 승격 + 중복 제거), `Core/Init.lua` (seedMemoFromExternal + /hg memo 슬래시), `Core/Storage.lua` (DEFAULTS.memo), `HealGuide.toc`, `UI/MainFrame.lua` (5번째 '메모' 탭)
- 맥앱 신규: `Models/MemoLines.swift` (MemoContent + ColorPreset), `Services/MemoPersistence.swift`, `ViewModels/MemoEditorViewModel.swift`, `Views/MemoEditorTab.swift`, `HealGuideTests/MemoPersistenceTests.swift`
- 맥앱 수정: `App/HealGuideApp.swift` (탭 추가)

**주요 기능:**
1. **맥앱 상시 메모 탭** — TextEditor 자동 높이, 폰트 10~32 슬라이더, 색상 프리셋 6개, 배경 투명도 0~100% 슬라이더. 무제한 줄 수
2. **애드온 메모 탭** — InputScrollFrameTemplate 멀티라인 + 동일한 폰트/색/투명도 컨트롤. 슬라이더/프리셋/체크박스 모두 **즉시 반영** (저장 버튼은 텍스트만 담당)
3. **HealGuideMemoFrame** — 독립 프레임, 드래그 이동, 잠금 체크, 내용 따라 높이 자동 조정, 전투 여부 무관 상시 표시
4. **동기화 정책** — Unix 타임스탬프 `updatedAt` 비교. 맥앱이 최신이면 lines/fontSize/fontColor/bgAlpha 만 동기화, show/locked/point 는 인게임 편집 우선
5. **priority=note 라인 상시 표시** — `_shared` 와 동일하게 전투 내내 표시 (스킬별 표시 경로에서는 중복 방지로 제외)
6. **슬래시 명령** — `/hg memo` 토글 + `/hg memo show/hide`

**잔여 이슈 (다음 세션 1순위):**

1. **맥앱 `ColorPreset.rgb` 를 Lua 값과 통일 (SUG-1 나머지)**
   - 맥앱 `MemoLines.swift` 의 노랑/주황/빨강/청록 5개 값이 애드온 Lua 프리셋과 다름
   - 사용자 경험: 맥앱에서 "청록" 선택 → 인게임 UI "청록" 버튼 클릭 시 다른 색으로 바뀜
   - 해결: Swift 값을 아래 Lua 값으로 일치
     - yellow: (1.0, 1.0, 0.0)
     - orange: (1.0, 0.5, 0.0)
     - red:    (1.0, 0.2, 0.2)
     - cyan:   (0.0, 1.0, 1.0)
     - green:  (0.4, 1.0, 0.2) — 이미 통일됨
   - 관련 테스트 (`test_serialize_fontColor_includesRGBAndPreset` 등) 도 값 수정

2. **맥앱 `save()` 경합 `isSaved` 오표시 (SUG-2)**
   - `save()` 가 `Task.detached` 로 백그라운드 저장 → 완료 후 `isSaved = true`
   - 저장 중 사용자가 편집해서 `markDirty` 호출 시 곧바로 `isSaved = false` 되지만, Task 완료 시 다시 true 로 덮어씀
   - 해결: `saveGeneration: Int` 도입. save 시 현재 세대 스냅샷 → 완료 시 세대가 여전히 일치할 때만 `isSaved = true`
