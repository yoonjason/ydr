## 주요 설계 결정 (세션 전체 누적)

1. **TimerBar → 가로/세로 Timeline 통합**. orientation 설정에서 선택 가능.
2. **모든 설정 /hg 창으로 통합** (슬래시 서브커맨드는 후방 호환 유지).
3. **데이터 생성 앱 → 애드온 자동 전달** (SavedVariables 직접 쓰기 + HealGuide_Generated.lua).
4. **스펙별 리포트 독립 저장** (`HGPT_Data["DiscPriest"] = ...`).
5. **secret spellID 방어**: type() 으론 부족 → pcall 로 감싸야 함 (Midnight 11.0+ 특성).
6. **CD 필터 제거**: 사용자 catalog 승인 = 필터 원칙. 축도(1262763) 같은 탈란트-프록 instant 스킬 보호.
7. **잠금 strict**: editMode override 제거. locked=true 면 무조건 이동 불가.
8. **AlertFrame 드래그**: anchor 가 1×1 px 투명이라 slot 에 직접 드래그 핸들러.
9. **타임라인 펄스 타이밍**: remaining=1 부터 scale 업, 0 에서 자연 소멸. 5초 이하 progressive 브레스(0→8%).
10. **테두리 색 단계**: >10s 없음 / 5~10 빨강 / 1~5 흰색 / ≤1 흰색+sin 펄스.

절차:
1. 앱 실행 (이미 빌드된 debug build 존재: `~/Library/Developer/Xcode/DerivedData/HealGuide-*/Build/Products/Debug/HealGuide.app`)
2. URL 붙여넣기 → Fetch
3. 힐러 자동 감지 (사용자는 신성 사제)
4. 신규 스킬 발견 시트 → 필요한 스킬만 체크 (기본 전체 해제)
5. "SavedVariables 저장" or "파일 저장"
6. 인게임 `/reload`
7. `/hg` 데이터 탭 → 방금 import 한 던전 보이는지
8. 해당 던전 입장 → Path A (스펙별 추천) 알림 뜨는지
