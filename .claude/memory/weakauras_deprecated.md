WoW 12.0 (Midnight) 에서 WeakAuras 는 더 이상 사용할 수 없다.

**Why:** Blizzard 가 Midnight 에서 WeakAuras 를 차단. 정확한 메커니즘은 미확인이나 사용자가 명시적으로 "위크오라는 한밤에서 더 쓸 수 없습니다" 고 확인.
**How to apply:** HealGuide 설계/기능 제안에서 WeakAuras 연동, Custom Trigger, WA export 등 위크오라 관련 기능을 절대 언급하지 않는다. 대안 알림 시스템은 HealGuide 자체 AlertFrame 으로 처리.
