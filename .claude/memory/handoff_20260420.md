2026-04-20 세션에서 Phase 5α 의 마지막 큰 슬라이스(랭커 데이터를 실제 인게임 가이드에 연결) 까지 끝내고 단일 커밋으로 정리.

**커밋:** `5455d53 추가: Phase 5α — 랭커 데이터 활용 인프라 + 안정화 종합`

**Why:** 사용자가 맥앱에서 랭커 데이터 수집은 잘 했지만 인게임 가이드가 전혀 안 떴음. 원인 추적 결과:
1. libs/ 누락으로 LibDualSpec 등 라이브러리 로드 실패 → MainFrame 자체가 안 뜸
2. EncounterEngine 이 HGPT_Data 중심 설계라 랭커 데이터만 있는 보스에서 activeSpecData=nil → OnCombatLog 가드에 걸려 무응답
3. EncounterTimelineBridge 가 로컬 reactions 만 조회, 랭커 미연동
4. Blizzard_StaticPopup_Game on-demand 로드 타이밍 때문에 차단 팝업이 계속 떴음

이 4건을 모두 잡고, 사용자 UX 요청(스킬 기본 해제, 저장 버튼 위치, 랭커 정책 3단 라디오, 보스 단위 계층 UI, 테스트 시작/중지 버튼) 반영.

**How to apply:** 다음 세션은 **인게임 실기 검증** 우선:
- /reload 후 랭커 탭에서 보스 단위 섹션이 잘 펼쳐지는지
- 테스트 버튼으로 알림 발동 → 중지 버튼으로 토글 동작
- 실제 윈드러너 첨탑 등 던전 진입 → 랭커 전용 모드 메시지 + AlertFrame 발동

이후 후속 슬라이스 후보:
- 보스 스킬 변형(난이도별 spellID 다름) 수동 그룹핑 테이블 (raid expert 권고)
- WCL encID ↔ Blizzard EJ ID 미스매치 fallback (M+ 미니보스/월드보스 대응)
- 랭커 데이터 'exclusive' 모드에서 알림 누락 빈도 측정 / 진단 UI

오늘 세션은 사용자가 작업 마무리 후 커밋+푸시 요청. 코드리뷰어 통과 (BLOCKER 0, 이전 SUGGESTION/NIT 6건 모두 RESOLVED).
