## 잔여 작업 (우선순위 순)

1. **실기 검증 (최우선)** — Mac 앱 재빌드 → 같은 WCL URL 재 가져오기 →
   재 import (기존 던전 삭제 후) → 인게임 풀. `[HG-NT] ... leadIns=Y reactions=Y`
   로그가 뜨는지, 램프 시퀀스가 사전에 순차적으로 뜨는지 확인. 타이밍/오작동
   있으면 보정.

2. **U2.5 — 네이티브/COMBAT_LOG 중복 방지** (30분)
   - `EncounterTimelineBridge.scheduledBossSpells[bossSpellID]` 를
     `EncounterEngine:OnCombatLog` 에서도 조회해 네이티브가 이미 예약한
     bossSpellID 는 스킵
   - 파일: `addon/HealGuide/Core/EncounterEngine.lua`, `EncounterTimelineBridge.lua`

3. **디버그 로그 정리** (20분)
   - `[HG-FORBID]`, `[HG-CL] boss cast`, `[HG-NT]` 등 진단용 print 를
     `addon.dprint` 로 교체하거나 DEBUG 플래그 체크 뒤로 이동
   - `addon/HealGuide/Core/Init.lua` 의 `DEBUG = true` 를 다시 `false`
   - `addon/HealGuide/Core/EncounterEngine.lua` 의 raw print 들을 dprint 로

4. **레이드 지원 (선택)** — NSRT BossTimelines 참조해서 "raid damage"
   카테고리 보스 스킬을 자동으로 램프 대상으로 승격하는 기능. 레이드는
   후순위. 메모리: `addon/HealGuide/Core/EncounterTimelineBridge.lua` 확장

## 핵심 컨텍스트 (새 Claude 가 알아야 할 것)

### 아키텍처
- **Mac 앱** (app/): SwiftUI macOS 14+, XcodeGen, WCL v2 GraphQL, FileCredentialStore
  (Keychain 대신 `~/Library/Application Support/HealGuide/credentials.json` 0600)
- **애드온** (addon/HealGuide/): Lua 5.1, TOC Interface 120000 (Midnight)
- **Lua 출력 스키마**: `{version=1, dungeonName, spec, bosses={[encID]={
  name, duration, timeline, reactions, leadIns}}}` — U3 에서 leadIns 추가됨
  → 기존에 import 한 데이터는 `leadIns` 비어있음, 재 import 필수

### 핵심 플로우
1. Mac 앱: URL+creds → fetchPlayerDetails(힐러 드롭다운) → SpecSpellCatalog
   체크박스 → fetchCasts 필터 → normalize(absolute+reactions+leadIns) → Lua
2. 애드온 import: ImportParser(pcall+setfenv 빈 환경) → Storage.AddDungeon →
   encounterIndex
3. 인게임 ENCOUNTER_START: EncounterEngine.OnEncounterStart 가 매칭 후
   activeSpecData 설정
4. **네이티브 타임라인 (C_EncounterTimeline, 12.0 신규)**: 지원 보스에서는
   EncounterTimelineBridge 가 eventInfo.spellID + duration 으로 사전 예측
   예약. leadIns[X] 역방향(offset 음수), reactions[X] 정방향(delay 양수)
5. COMBAT_LOG 폴백: 미지원 보스는 SPELL_CAST_SUCCESS 로 reactive 만 가능

### 알려진 이슈
- **네이티브 지원 보스 중복**: 현재 네이티브가 예약한 뒤 COMBAT_LOG 도 같이
  발화해서 알림 2회 가능. U2.5 로 fix 예정.
- **reactions 커버리지**: 레퍼런스 로그 1개에서 추출한 boss→player 매핑이라
  보스가 많은 스킬을 쓰지 않으면 reactions 키가 적음. leadIns 는 모든 보스
  캐스트마다 생성돼 커버리지 더 좋음.
