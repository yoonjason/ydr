2026-04-21~22 세션. 랭커 데이터 기반 힐 추천의 빈틈을 메우고, 보스 전투 중 전술 안내 패널을 신설. 같은 세션에서 code-reviewer 지적 18건 전부 반영.

**Why:** 기존 랭커 데이터 매칭은 보스 스킬 ID 정확 일치만 시도해서 실제 인게임에선 상당수 알림이 누락됨 (WCL 과 실제 시전 ID 불일치, secret spellID 등). 공략 가이드(전술 텍스트) 는 한 줄만 표시되고 힐 아이콘과 같이 사라져서 힐러가 보스 기믹을 놓치기 쉬웠음. 두 문제를 통합 해결.

**커밋 예정 (이 세션에서 푸시 대상):**
- 애드온: RankerDataLoader / EncounterEngine / EncounterTimelineBridge / Storage / ImportParser / Init / AlertFrame (기능 + 리뷰 피드백 모두 포함)
- 맥앱: RankerCollectionModels / TacticalGuide / LuaOutput / WarcraftLogsAPIClient / CharacterRankingsService / RankerLuaSerializer / LuaGenerator / RankerCollectionViewModel / TalentBuildViewModel / ReportViewModel
- 테스트: RankerLuaSerializerTests / RankerCollectionViewModelTests (추가)
- 환경: .claude/ 변경 있으면 같이

**주요 변경 (기능):**
1. WCL `characterRankings` 에 `partition` 동적 조회 후 전달 — 현재 시즌 데이터로 한정 (이전엔 Argus 2017 로그 혼입)
2. Boss spell name 기반 2단 매칭 + encID 기준 Top N 3단 대체 추천 — 힐 매칭 실패 극단 케이스도 커버
3. 전술 패널 `HealGuideTacticPanel` 신설 — 별도 프레임, 4줄 동시 표시, 드래그 이동, 우선순위 색상, 보스 시전 시작~끝 수명, "보스 전체 주의사항" 은 스킬 시전 전에도 단독 표시
4. 기본 전술 카탈로그 + 사용자 편집본 merge 후 `HealGuide_Generated.lua` 에 `_sharedTactics` + `tactics[bossSpellID]` 구조로 저장
5. 12.0 Midnight secret spellID 방어 통합 (`safeIndex` 일관 적용)
6. StaticPopup "애드온 차단" 팝업 이중 방어 (`Blizzard_StaticPopup_Game` on-demand 대응)

**How to apply (다음 세션 작업 순서):**
1. **인게임 실기 검증** (가장 중요) — `/reload` 후 실제 M+ 던전/레이드 진입:
   - 보스 스킬 시전 시 전술 패널에 여러 줄 뜨는지
   - 시전 중단(interrupt/실패) 시 텍스트 사라지는지
   - 드래그로 패널 위치 이동 가능한지
   - 힐 아이콘(랭커 기반) 과 전술 텍스트가 각자 수명대로 동작하는지
   - 같은 보스 스킬 반복 시 중복 알림 없는지
   - 여러 보스 스킬 동시 시전 시 라인 스택 정상 동작
2. **_name 매핑 버그 재확인** — 어제 handoff_20260421 에 있던 WCL encID ↔ Blizzard EJ ID 공간 불일치 문제. 이번 세션에서 직접 손대지 않음. 재수집 후에도 여전히 잘못된 이름이 뜨면 C (WCL 응답 활용) 방향으로 가야 함
3. **남은 raid expert 권고 — Spell API 래퍼 격리, boss spell ID 변형 그룹핑** 등은 다음 슬라이스 후보
4. **AlertFrame 과 TacticPanel 의 위치 프리셋** — 현재는 기본값 + 드래그 저장. 필요하면 전술 편집 탭에 "프리셋 위치" 선택 UI 추가
