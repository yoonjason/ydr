사용자에게 진행 방향을 설명할 때는 기술 용어(예: reactions, fallback, LookupBossReactions)나 영어 함수명을 그대로 나열하지 말고 한글로 풀어서 설명한다.

**Why:** 사용자가 "2/3단 로직에 공략 가이드 reactions 도 참여하도록 확장" 이라는 설명이 무슨 뜻인지 모르겠다고 직접 지적함. 한글로 풀어 쓰라는 명시적 요청.

**How to apply:**
- 영어 식별자가 꼭 필요하면 한번만 괄호로 참조: "공략 가이드(activeSpecData.reactions)"
- "fallback" → "대체 경로" / "대체 추천" / "보완 동작"
- "확장" → "추가" / "늘림"
- "merge" → "합치기" / "섞기"
- "로직" → "동작" / "흐름" / "순서"
- 단계 설명 시 "1단/2단" 보다 "첫 번째 단계" 같은 풀어쓴 표현 우선
- 코드 리뷰 결과나 에이전트 보고를 인용할 때도 사용자가 이해하기 쉬운 말로 한번 정리해서 전달
- file:line 형식의 코드 참조는 여전히 유용하므로 유지하되, 그 앞뒤 문장은 한글 풀어쓰기
